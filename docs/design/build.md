# 构建输入与 Web 兼容基线

> 本文是[总体设计](../design.md)的专题文档：锁定 Web 子集验收目标、构建输入、扩展管线与资源处理。语言语义见 [language.md](language.md)，宿主能力与框架验收见 [framework-acceptance.md](framework-acceptance.md)。

## 验收目标与宿主边界

Web 目标是浏览器式客户端子集，而不是“非 Web”宿主树。应用以严格的 ESM/Web 语义构建和运行；宿主提供 DOM 风格的文档树、节点属性与文本、父子兄弟关系、事件分发、样式应用，以及运行所需的 Web 全局对象。最终 Web 宿主预期由 [Blitz](https://github.com/DioxusLabs/blitz) 一类 Rust HTML/CSS 渲染引擎承接。构建管线、Build 产物、字节码和快照格式不得依赖具体宿主引擎：不记录 Blitz／浏览器的类型、版本或内部句柄，也不把 DOM 实现打包进字节码。

宿主绑定决定实际节点树与样式应用；构建输入、字节码和 Build 只依赖 Web 宿主声明，不记录具体引擎的类型或句柄。当前首屏验收由 `yield-blitz` 承接，替换宿主只改变绑定实现。

| 验收目标 | 锁定的运行时入口 |
| --- | --- |
| React Web 客户端子集 | `react@19.2.0`、`react-dom@19.2.0` 的 `react-dom/client`、`react/jsx-runtime` 和 `scheduler@0.27.0` 的生产包。React DOM 自带 reconciler，验收基线不要求应用直接依赖 `react-reconciler`。 |

React DOM 是首个锁定验收目标，不是 Web 目标的全部；构建管线不按框架名特化，其他 Web 客户端框架只要遵循同一 ESM、Web 条件解析和宿主绑定契约，就复用同一构建。React Native/Fabric 和其他非 Web 平台层不是验收目标。完整浏览器外壳——导航与历史、Service Worker、扩展、开发者工具、浏览器 UI、完整 HTML 解析和 CSS 布局——属于宿主职责，不是本构建接口的承诺。`react-dom/server`、RSC 等 SSR 入口是独立运行环境；hydration 复用同一客户端构建，属于 Web 目标，但当前首屏验收不覆盖 hydration，待宿主 DOM 子集支持服务端标记后按同一构建验收。

## 构建输入与模块图

应用入口可直接使用 JS/TS/JSX/TSX，并从源码按模块解析依赖。扩展前端与核心共享一张可达模块图：对每个模块执行解析/加载、按模块转换，再由同一 ESM 链接层解析转换结果中的静态导入并发现后续模块；转换器不得私自链接或改变核心 ESM 的活绑定语义。默认路径接受严格 ESM，扩展路径由官方 Web/React 预设启用额外语法、Web 条件包解析与资源导入。扩展可组合实现这些阶段，但首版只承诺核心 ESM 与官方 npm/React 预设，不冻结第三方插件 API；扩展不替代核心链接器、语法子集校验或字节码编译器。Web 目标不改变模块只求值一次、导出是活绑定以及只有入口显式导出对宿主公开的规则。

## 模块解析与加载

模块解析与加载是同步构建期操作。解析器将导入请求和 referrer 映射到稳定、非空的逻辑模块 ID，再按 ID 加载源码；同一逻辑 ID 在一次构建中必须唯一对应同一内容，冲突时报构建错误。项目源码 ID 相对项目根规范化；npm 依赖 ID 由包名、可得的版本声明和解析后的包内相对路径组成，不含机器绝对路径。`exports` 条件选择的结果进入包内相对路径，避免同一包的不同入口复用同一 ID。加载可跟随 `node_modules` 中的符号链接以支持 workspace，但必须解析并校验目标是普通文件；不得执行包代码、安装脚本或其他构建脚本。该边界是读取边界，不是对恶意依赖内容的沙箱。

## 官方 Web/React 预设

官方 npm 预设从调用方已安装的 `node_modules` 读取依赖，不安装、更新或锁定包，也不承诺完整的跨机器可复现性。预设必须定义其工具版本、解析根、`package.json` 条件导出的条件集合和优先级，以及无 `exports` 包允许的字段/子路径回退规则。

Web 预设固定按客户端生产模式解析：启用浏览器客户端条件（至少 `browser`、`import` 和 `production`），并以 `default` 作为回退；不启用 `react-server`、`node`、`development` 或由运行宿主偶然提供的条件。React 预设选择 `react-dom/client` 的生产入口，不选择 `react-dom/server`、RSC 或 Node 内建。条件选择不得由运行宿主环境意外改变；同一输入、同一预设版本和同一依赖内容必须得到同一模块选择。若包声明 `exports` 而请求未被其允许则报解析错误，不回退到包内私有路径；无 `exports` 的包仅使用预设明确定义的字段/子路径回退规则，未定义的字段不隐式猜测。应用入口显式导出仍是宿主公开 API，依赖内部导出不自动暴露；VM 不负责模块加载。

## 转换

转换按模块进行，产物必须是核心可链接的 ESM，转换产生的导入照常进入同一图。TypeScript 转换只移除类型语法，不声称类型检查；JSX 按预设配置转换为指定 runtime，Web/React 预设使用 `react/jsx-runtime` 的生产 automatic runtime，不生成对 `React.createElement` 的隐式全局依赖。CJS 转换仅覆盖静态可分析子集：字面量 `require`、常见 `module.exports` / `exports` 赋值与属性访问、受支持的 `process.env.NODE_ENV` 生产分支，以及所覆盖的循环初始化行为；不承诺完整 Node wrapper、Node 内建或任意 CJS 语义。动态或无法静态确定目标的 `require` 必须在构建期报错，不能留下运行时 require。转换不得破坏 ESM 活绑定或所覆盖 CJS 初始化行为；无法安全表达的写法明确拒绝，不以近似行为静默通过。

公开的源码和图转换接口使用 workspace 固定版本的 Oxc AST，不保证跨 Oxc 版本兼容性。转换不直接访问链接表或私有 CFG；图转换后的链接绑定由核心重新计算。VM 和字节码契约保持独立于 Oxc。

对 React 等通过 `process.env.NODE_ENV` 选择生产实现的包，预设按固定 `production` 值折叠受支持的静态比较/分支；不注入完整 `process` 对象，不执行包代码。其余动态分支按 CJS 规则拒绝。

## Web 资源与样式

资源扩展只处理可达模块显式导入的资源，不自动发现未引用文件。普通 CSS 导入编译成以规范化逻辑模块 ID 为身份、无导出的副作用 ESM；模块求值调用宿主，由宿主把资源字节接入作者样式系统。Build 保存 `asset:` 加完整逻辑模块 ID 的不透明 URI 与原始字节：先遍历 preload，再遍历 entry，各自按静态依赖源码顺序深度优先收集，同一 ID 只保留首次读取的资源记录，之后的重复导入直接复用该记录且不再读取文件，不报错。资源数据纳入构建身份；VM 不解释资源，加载 Build 也不应用样式。Blitz 插入原生 `style` 节点，快照恢复实际节点树而非重放资源导入。

CSS Modules 仍是目标设计：同时生成供脚本导入的类名映射 ESM 与供宿主消费的改写 CSS。官方预设的类名生成必须由规范化资源 ID、局部类名和固定配置确定，不依赖随机数或机器绝对路径；映射与改写结果进入构建身份。当前普通 CSS 路径不处理 CSS 内部 `@import` 或 `url()`。

其他 Web 资源（图片、字体等）若由预设纳入，必须使用同一逻辑 ID、去重、顺序和身份规则，并产出宿主可消费的 URL 或字节记录；首版验收只锁定 CSS 与 CSS Modules，不要求构建期下载或优化这些资源。

## 诊断与构建身份

编译错误包含逻辑模块 ID、源码位置、阶段和原因。受支持的转换应提供位置映射，尽可能报告原始源码行列；转换器不能映射的位置必须标明是转换后位置，不得冒充原始位置。源码映射/变量名等诊断旁路产物可选，不参与执行、恢复或构建身份。Build 身份由最终执行相关模块图、字节码和资源数据决定；解析条件或转换配置本身不另立身份字段，但其导致的模块选择、代码或资源差异必须反映在构建产物及其摘要中。未改变最终构建产物的配置差异不改变 Build 身份。实际依赖版本由调用方管理；依赖内容变化会改变产物身份，但工具版本、安装布局和上游包版本不构成可复现性保证。

构建只读取源码、包文件和资源，不执行包代码、不运行 Blitz 或浏览器；`window`、`document` 等 Web 全局由宿主通过 preload 或静态宿主模块提供，构建不根据宿主环境自动注入。Web 全局和 DOM 绑定在 VM 创建或恢复时按声明链接。缺少宿主声明或实现属于链接错误，不得在运行时回退到 Node 或另一套 DOM。
