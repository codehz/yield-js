# 构建句柄：每次激活去掉原子引用计数

`Vm` 在构造时持有只读 `Build`. 每次进入 `execute_frame` 都克隆一次构建句柄, 以便在嵌套调用和可变 VM 操作期间安全借用指令与变长操作数. 原实现使用 `Arc<Build>`, 每次脚本激活都做一对原子增减. 宿主绑定文档已明确 VM 不承诺跨线程安全, 因此改为 `Rc<Build>`; 只读构建与快照内容不变, 只去掉原子引用计数.

## 环境与命令

Apple M2 (24 GiB), macOS 27.0.1, rustc/cargo 1.99.1. 基线是提交 `b4ebb52`; 最终版是同一工作树上的改动. 两版各跑 A/B/C 三批, 每批 `--samples 5`, 进程内预热 2 次; 报告使用每批中位数. 复现:

```sh
cargo bench -p yield-harness --bench baseline -- --samples 5
```

基线原始样本复用 [调用分派对照](../call-dispatch/dispatch-a/b/c.csv); 本轮样本在 [build-handle/](build-handle/) 的 `rc-a/b/c.csv`.

## 结果

| 负载 / 指标 | 基线 (µs) | 最终版 (µs) | 变化 |
|---|---:|---:|---:|
| 短调用 / `entry_first` | 240.17 | 225.46 | −6.1% |
| 短调用 / `entry_steady_5` | 1207.92 | 1143.08 | −5.4% |
| 异步生成器 / `entry_first` | 17.71 | 16.96 | −4.2% |
| 异步生成器 / `entry_steady_5` | 70.08 | 66.92 | −4.5% |
| 闭包读写 / `entry_steady_5` | 1982.33 | 1971.04 | −0.6% |
| React 首提交 / `entry_steady_5` | 2022.00 | 2018.33 | −0.2% |
| React 更新 / `entry_steady_5` | 9908.00 | 9945.04 | +0.4% |
| 数值/分支 / `entry_steady_5` | 3992.62 | 3958.71 | −0.8% |

短调用和异步生成器的收益跨三批方向一致; 其调用路径每轮构造大量脚本激活, 原子计数是可直接观察到的固定成本. React 和闭包没有稳定的额外收益, 静态属性 +0.8%、`await` 成功 +2.3% 按样本波动处理.

## 边界

- `Build` 仍是只读且不可替换; 快照、构建摘要、字节码版本不变.
- `Vm` 继续是线程内对象; 宿主绑定声明和跨线程交付仍按其文档约定, 不在 VM 外部共享 `Vm`.
- 没有采用裸指针直接借用 `Build`. 该实验在短调用上略快, 但需要额外的 unsafe 别名不变量; 本轮保留 `Rc` 的持有关系和可检查的生命周期.
